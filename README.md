# Linear Algebra Practice

This repository is a collection of worked linear algebra exercises organized into three Jupyter notebooks. The solutions combine mathematical explanations with Python calculations to verify results, explore patterns, and illustrate geometric ideas.

## Chapter 1: Linear Equations in Linear Algebra

[`chapter1.ipynb`](chapter1.ipynb) introduces the foundations of linear algebra through selected exercises from Sections 1.2, 1.3, 1.4, and 1.7–1.10.

Topics include:

- solving linear systems by row reduction;
- polynomial interpolation;
- vector equations and linear combinations;
- matrix equations and spanning sets;
- linear independence;
- linear transformations and their standard matrices;
- one-to-one and onto mappings;
- transition matrices and applied linear models.

## Chapter 2: Matrix Algebra

[`chapter2.ipynb`](chapter2.ipynb) develops matrix methods through selected exercises from Sections 2.1–2.5 and 2.7.

Topics include:

- matrix operations and matrix powers;
- inverse matrices and invertibility;
- the Invertible Matrix Theorem;
- numerical sensitivity and condition numbers;
- partitioned matrices;
- LU factorization and related matrix factorizations;
- applications to circuits and computational models;
- transformations, homogeneous coordinates, perspective projection, and color conversion in computer graphics.

## Chapter 3: Determinants

[`chapter3.ipynb`](chapter3.ipynb) studies determinants through selected exercises from Sections 3.1–3.3.

Topics include:

- computing determinants by cofactor expansion;
- experimental investigation of determinant identities;
- the effects of row operations, transposes, products, inverses, and scalar multiplication;
- determinants and numerical conditioning;
- Cramer's rule and the adjugate formula;
- area and volume interpretation;
- volume scaling under linear transformations.
